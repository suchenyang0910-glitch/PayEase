## V1 定位

面向已接入企业的受薪员工，平台以 Telegram 授权作为 Mini App 的唯一登录方式，把用户申请、企业薪资核验与持牌机构授信连接起来。助贷公司仅承担获客、资料服务、流程协同与贷后提醒；准入、实名/KYC、授信、定价、放款及合同主体均由持牌机构负责。

> 上线前须由业务所在地的持牌机构、法务与合规团队确认产品、数据处理、营销及催收规则。本资料不构成法律或合规意见。
