## 1. 参与方与职责

| 主体            | 可做                                                            | 不可做                                     |
| --------------- | --------------------------------------------------------------- | ------------------------------------------ |
| 用户            | 申请、选择工厂、签协议/授权、查看状态账单、在到期时主动发起还款 | 修改获批额度、利率、合同、核销结果         |
| KhmerX 助贷运营 | 资料完整性、补件、企业催办、服务费复核、客服与工单              | 授信、定价、最终合同、放款、贷款核销       |

| 持牌机构        | KYC/征信、授信、报价、合同、放款、本息账、核销、贷后            | 与 KhmerX 共享信贷核心数据库或委托其决策   |

## 2. 产品规则

### 2.1 金额、期限与价格

- 币种 USD；所有金额使用最小货币单位字符串和币种，严禁 JS `number`。
- 单笔申请 USD 10–500；一次申请仅对应一笔借款，进行中订单不可重复申请。
- `contractualTermDays` 只能为 15 或 30；`pricingDays`、舍入方式、宽限期及节假日规则必须由持牌机构在报价/合同快照冻结，前端不得自行计算最终金额。
- 默认年息 18%（月息 1.5%）和默认融资居间服务费 10.5%/月，均仅为版本化后台默认值，不构成用户承诺；展示以批准报价为准。

### 2.2 发薪节点与分期

工厂可配置 1 或 2 个发薪节点（日期 1–28 或月末），用于在职/收入事实核验、还款日提示与用户还款能力评估。发薪节点不得成为工资代扣指令。

两期计划：

```text
第一期本金 = floor(总本金 / 2)
第一期利息 = floor(总利息 / 2)
第二期本金 = 总本金 - 第一期本金
第二期利息 = 总利息 - 第一期利息
```

所有最小货币单位余数进入第二期。每个节点有工资发放日后 3 个自然日缓冲；实际逾期处置须遵循已签合同和法务版本。

### 2.3 钱包、提现与本息回收

- 持牌机构域为每名已放款用户维护受监管/签约通道支持的托管钱包子账本；KhmerX/PayEase 只读取受控余额与交易投影，不持有用户资金。
- 放款成功并经持牌机构/支付通道验签确认后，钱包余额才变为可用；用户可提现至已验证的本人银行卡。
- 用户到期或提前还款时，在 PayEase 主动发起还款，选择本人银行后跳转银行或支付机构完成最终授权；持牌机构以已验签回调作为还款成功及核销依据。
- 支付密码仅是 Mini App 内提现确认的第二层保护；密码哈希、银行卡令牌、提现订单、资金回调与最终账务均由持牌机构域管理。不得保存明文密码、银行登录密码、OTP 或完整银行卡号。
- 扣款失败、取消授权、余额不足、超时或账务不一致均进入异常工单；不得自动结清或通过前端结果改变账务。
- V1 已废止“工资代扣 / 用户本人账户代扣 / 用户主动付款”三种回收方式旧口径；产品、状态机、字段字典和后台配置中均不得继续出现该枚举。

### 2.4 融资居间服务费与工厂结算

- 费用名称：融资居间服务费 / Financing Brokerage Remuneration / ប្រាក់កម្រៃសេវាអន្តរការហិរញ្ញវត្ថុ。
- 费率为工厂有效版本优先、平台默认版本兜底；实际放款后建立应收，D+1/D+2/D+3 提醒，D+3 为最晚支付日。
- 服务费只向 KhmerX 指定账户支付；不得扣减放款额、不得写入贷款本息账单、不得进入任何扣款指令。
- 工厂分润规则二选一：固定月度金额或 `实际放款本金 × 分润系数`。只对已放款、服务费已确认且未退款的订单结算；具体结算周期与退款冲回规则需版本化。

## 3. 申请至结清流程

```text
Telegram 自动登录与语言恢复
→ 用户选择工厂、完成 KYC/资料采集
→ 确认服务协议、数据处理与企业核验授权
→ KhmerX 资料完整性审核
→ 工厂 HR 核验事实
→ KhmerX 安全推送申请包
→ 持牌机构独立审批并回传要约
→ 用户确认报价、合同、还款授权说明及独立授权；手机签名/必要视频
→ 持牌机构双人审批后放款至其权威托管钱包子账本
→ KhmerX 独立建立服务费应收和提醒
→ 用户主动发起银行/支付机构授权扣款回收本息，持牌机构核销
→ 异常处理或结清
→ 工厂分润对账与结算
```

## 4. 四端需求

### 4.1 PayEase Mini App

- 首页、借款、钱包、我的四个 Tab；中/英/高棉三语及会话语言恢复。借款列表由“借款”页承载。
- 申请：身份/住址/手机、两名联系人、工厂选择、证件拍摄、活体采集（V1 人工复核）、可选财富/流水文件。
- 要约/合同：完整费用、实际到账、还款节点、还款授权说明、授权版本与签署证据。
- 钱包：可用余额、放款到账、提现、还款状态、服务费支付记录和交易详情；真实充值、用户间转账、扫码支付和二维码收款不属于 V1。

### 4.2 KhmerX 运营后台

- 资料队列、补件、企业催办、服务费凭证经办/复核、客服投诉、分润对账。
- 只显示必要的状态投影；不得创建或修改持牌报价、合同、放款、核销。

### 4.3 KhmerX Enterprise

- HR：花名册导入、在职/工资事实核验、SLA 待办。
- 财务：V1 不承接贷款本息扣款、还款授权或核销能力；不展示扣款清单、钱包、合同或还款处理页面。
- 平台管理员：工厂、部门—角色—账号、发薪节点、工厂费率/分润版本及授权收款主体。

### 4.4 持牌机构端

- 机构组织/RBAC、KYC/征信结论、报价、合同、放款双人审批、本息账单、核销双人审批、异常/投诉最终处理。
- 征信原始资料与内部评分永不返回 KhmerX 域。

## 5. 用户可见文案与禁止披露

普通页面使用“资料审核中、正在确认在职信息、额度审核中、需要补充资料、审核结果已更新、放款处理中、款项已发放”。最终合同、费用确认、账单和投诉页必须使用法务批准的法定主体与披露。

不得向用户或企业端暴露内部风控、评分、征信报告、完整银行卡/证件、联系人信息及跨工厂数据。
