# 三方合作边界与 SLA

## 1. 合作角色

| 角色     | 负责事项                                                                          | 明确不负责                                     |
| -------- | --------------------------------------------------------------------------------- | ---------------------------------------------- |
| 助贷公司 | Telegram 获客与服务、资料收集及质检、企业接入、用户通知、客服协同、独立服务费结算 | 授信、定价、合同、放款、账单权威记录、催收决策 |
| 持牌机构 | KYC/AML、反欺诈、授信、利率与费用审批、合同、放款、账单、贷后与投诉最终处理       | 企业 HR 原始数据的真实性担保                   |
| 企业     | 经用户授权的在职/薪资核验、企业数据维护、员工异议处理                             | 影响授信决策、访问员工借款/逾期信息            |

## 2. 责任分界

| 场景            | 主责           | 协同                       | 用户侧口径                           |
| --------------- | -------------- | -------------------------- | ------------------------------------ |
| 证件上传失败    | 助贷公司       | 持牌机构                   | 指引补件，不披露内部规则             |
| 企业核验错误    | 企业           | 助贷公司                   | 发起核验更正，暂停流转               |
| KYC/风控拒绝    | 持牌机构       | 助贷公司                   | 返回合规原因码或人工复核状态         |
| 报价/合同不一致 | 持牌机构       | 助贷公司                   | 暂停签约，重新生成报价快照           |
| 放款失败/错账   | 持牌机构       | 助贷公司、支付通道         | 机构处理，助贷同步进度               |
| 助贷服务费争议  | 助贷公司       | 持牌机构（涉及报价时）     | 依据服务协议、费用快照与退款规则处理 |
| 企业分成争议    | 企业与助贷公司 | 持牌机构仅在合同需要时知悉 | 不影响用户授信和账单                 |

## 3. SLA 基线

| 事项             |                 目标时限 | 责任方            | 超时动作                           |
| ---------------- | -----------------------: | ----------------- | ---------------------------------- |
| 资料完整性审核   |             4 个工作小时 | 助贷公司          | 转主管队列                         |
| 企业单笔核验     |               2 个工作日 | 企业              | 第 1 天提醒，第 2 天关闭或人工跟进 |
| 机构受理回执     |                   5 分钟 | 持牌机构          | 自动重试、异常工单                 |
| 审批结果回传     |     1 个工作日或产品约定 | 持牌机构          | 向用户显示“审核中”并升级工单       |
| 放款结果回调     |           指令后 30 分钟 | 持牌机构/支付通道 | 对账异常工单                       |
| P1 数据/接口故障 | 4 小时响应，1 工作日缓解 | 事件归属方        | 启动事件指挥与状态公告             |

## 4. 数据与财务边界

- 三方物理隔离部署，禁止共享生产库、管理员、密钥和原始账务。
- 企业只接收已授权的核验字段；不得看到授信、利率、账单或逾期。
- 持牌机构的本金、利息、合同、放款和账单为权威账务；助贷不得改写。
- 助贷服务费/手续费、企业分成在各自独立账本结算；每笔均需关联冻结的费用规则、服务履约证据及税务凭证。
- 数据事件与结算事件均使用全局 `trace_id`、来源事件 ID、版本号和审计日志关联。

## 5. 升级与治理

业务日常由三方运营负责人处理；涉及数据泄露、资金差异、用户重大投诉、监管问询或持续 SLA 违约时，升级至三方负责人和合规负责人。每月复盘 SLA、异常率、投诉、对账差异及权限变更。
