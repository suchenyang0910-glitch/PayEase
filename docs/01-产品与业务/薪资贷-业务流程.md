# 薪资贷业务流程

## 端到端流程

```mermaid
sequenceDiagram
    actor U as 用户（Telegram）
    participant A as 助贷平台
    participant E as 企业 HR/财务
    participant L as 持牌机构
    participant P as 合规支付/还款通道

    U->>A: Telegram 授权登录、填写证件/银行卡、选择金额期限、提交申请
    A->>U: 展示授权字段、用途、有效期
    U->>A: 明确同意授权
    A->>E: 发起最小必要的在职/薪资核验
    E->>A: 返回核验结论或补充请求
    A->>L: 推送申请、授权凭证与核验结论
    L->>U: 按机构流程完成实名/KYC（如需）
    L->>L: KYC/反欺诈/授信/定价决策
    L-->>A: 审批结果、合同或补件要求
    A-->>U: 通知状态与下一步
    U->>L: 阅读并签署合同
    L->>P: 指令放款
    P-->>U: 到账
    L-->>A: 放款与账单状态
    A-->>U: 还款提醒与账单入口
```

## 异常分流

```mermaid
flowchart TD
    S[用户提交申请] --> C{资料完整？}
    C -- 否 --> B[通知补件并保存草稿]
    C -- 是 --> A{授权有效？}
    A -- 否 --> R[重新展示授权并确认]
    A -- 是 --> V[企业核验]
    V --> M{核验匹配？}
    M -- 需补充 --> B
    M -- 不匹配 --> X[告知无法继续，可提交异议]
    M -- 匹配 --> L[持牌机构审核]
    L --> D{机构结论}
    D -- 补充/人工复核 --> B
    D -- 不通过 --> N[由机构返回合规说明]
    D -- 通过 --> K[用户签约]
    K --> F[机构放款]
```

## 数据最小化清单

| 数据类别 | 推荐字段                                             | 数据接收方                           | 目的             |
| -------- | ---------------------------------------------------- | ------------------------------------ | ---------------- |
| 身份资料 | 身份证号码、身份证正反面、姓名（前端及后台脱敏展示） | 持牌机构；助贷方按授权辅助采集       | KYC、签约        |
| 收款资料 | 本人银行卡号、开户行/卡类型（脱敏展示）              | 持牌机构及合规支付通道               | 绑卡、放款、还款 |
| 企业核验 | 企业 ID、在职状态、入职月、薪资区间、核验时间        | 持牌机构；助贷方仅留流程所需结果     | 贷前核验         |
| 账务状态 | 账单状态、应还日期、金额区间                         | 用户、持牌机构；助贷方按权限用于提醒 | 贷后服务         |

不采集或不默认共享：通讯录、Telegram 聊天内容、与身份核验无关的相册内容、精确位置、完整工资流水、与申请无关的家庭成员数据。
