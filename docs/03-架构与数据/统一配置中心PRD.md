# 统一配置中心 PRD（Demo）

## 1. 目标

Demo 使用一个后台统一维护持牌机构与产品参数、助贷收费、企业分成与结算规则。正式生产环境仍应按权限与审批流隔离；本阶段重点验证配置体验和前端展示结果。

## 2. 配置模块

| 模块       | 配置项                                                          | Demo 默认值                                                            |
| ---------- | --------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 机构信息   | 机构名称、代码、状态、接口地址占位                              | Partner Finance / PF-001 / 已启用                                      |
| 产品参数   | 产品名称、适用企业、客群、币种、最低/最高金额、可选期限         | Salary Flex / 全部企业 / 在职员工 / USD / $10–$5,000 / 10天、1/3/6个月 |
| 计息与还款 | 计息基础、名义年利率、分期方式、还款日规则、是否放款扣费        | 按剩余本金 / 18% / 等额分期 / 放款日对应日 / 否                        |
| 机构费用   | 费用名称、计算方式、金额/比例、收取时点、披露文本               | 占位规则，仅演示                                                       |
| 助贷收费   | 服务费/手续费、计算方式、收取主体、收取时点、退款条件、税务主体 | 服务费 2%，签约后收取，演示主体                                        |
| 企业分成   | 企业、分成基数、比例/固定额、结算周期、账单格式、审批人         | 按服务费 20%，月结，财务审批                                           |
| 接口配置   | 申请、签约、放款、账单、回调地址与状态                          | 演示占位，不发起真实请求                                               |
| 原因码     | 机构拒绝原因码、用户可见三语说明、是否可补件                    | KYC_PENDING / 待补充身份资料                                           |

## 3. 页面与交互

1. 左侧导航：产品与机构、收费与分成、接口与原因码、发布记录。
2. 每次修改仅保存“草稿”；Demo 可一键“发布演示版本”。
3. 发布后生成版本号，用户端申请页应读取已发布产品的币种、额度、期限和费用展示。
4. 金额和费率输入实时校验：最低金额不得大于最高金额；期限至少选择一项；比例介于 0–100。
5. 所有费用项目必须包含收费主体、收取时点、退款条件和三语披露占位。

## 4. 数据模型（Demo）

`lenders`、`loan_products`、`product_terms`、`fee_rules`、`enterprise_commission_rules`、`integration_configs`、`reason_codes`、`config_versions`。

发布时，将各配置序列化为 `product_config_snapshot`；用户端只读取最新的已发布快照，避免草稿影响演示数据。
