# S0.2-P0d：五类角色身份域与 RBAC 矩阵（Mock 权限基线，S1 IdP 输入）

> 生效前提：本文档仅定义身份域边界、页面/动作授权矩阵与 Fixture 基线。**不接任何真实 IdP**（无 SAML/OIDC 回调、无 SCIM、无 AD/LDAP），S0.5 所有 mock 权限只在前端本地状态中生效，不产生任何真实 token 或 session。
>
> 红线：在 S0.2 隔离基础设施（AWS 三域账号 / 区域合规 / KMS CA 矩阵）签字完成之前，严禁把以下任何角色配置写入 AWS IAM、Cognito、Auth0、Azure AD、Keycloak 等真实身份系统。

## 1. 五类角色身份域（物理隔离原则）

| 域代码 | 角色中文名         | 角色英文标识       | 物理登录域（S1 生产）           | 可访问网络段          | 永不出现的数据字段                                                |
| :----- | :----------------- | :----------------- | :------------------------------ | :-------------------- | :---------------------------------------------------------------- |
| `OPS`  | 平台运营           | `ops-admin`        | `ops.payease.io`                | 助贷域 + 运营域管理段 | 银行卡号全文、薪资具体金额、身份证全文、企业税号全文              |
| `BRK`  | 助贷经纪（Broker） | `broker-officer`   | `broker.payease.io`             | 助贷域应用段          | 银行卡号任何字段、还款银行流水、财务对账差异、HR 核验备注全文     |
| `LEND` | 持牌机构（Lender） | `lender-partner`   | `lender-<partnerid>.payease.io` | 机构域独立段          | 其他合作机构数据、雇主 HR 联系方式、员工手机号、身份证后 4 位之外 |
| `HR`   | 企业 HR 核验员     | `employer-hr`      | `hr-<taxid>.payease.io`         | 企业域 HR 段          | 财务对账数据、其他企业 HR 数据、助贷审批意见、放款银行账户        |
| `FIN`  | 企业财务对账员     | `employer-finance` | `fin-<taxid>.payease.io`        | 企业域财务段          | HR 核验备注、员工身份证、部门层级、助贷审核决策链路               |

**三域物理隔离（强制）**：

- 助贷域（broker/ops）：`10.10.0.0/16`
- 机构域（lender）：`10.20.0.0/16`
- 企业域（hr/finance）：`10.30.0.0/16`

三域之间默认 deny-all；仅通过 VPC Endpoint Service + 白名单 Principal 的跨域 AssumeRole 放行特定接口（S1 API 契约层定义）。VPC 对等连接（peering）全局禁用。

## 2. 页面 × 动作 × 角色 RBAC 矩阵

## 3. S0.5 Mock 权限实现（纯前端，无后端）

S0.5 中所有权限由各门户的 `src/mocks/*-mock-auth.static.ts`（下一步补充，若需要演示按钮禁用）本地模拟：

- 5 个角色按钮 dropdown（演示切换角色），切换后对应页面的 403 区域显示占位横幅。
- 任何 `403` 动作按钮：`disabled={!can(role, action)}`，并 tooltip 说明"仅 XXX 角色"。
- 切换角色不产生真实 cookie/token，纯 useState 本地。

Fixture 预留（S1 API 契约测试输入）：

```
fixtures/rbac/:page__:action__:role__.json
  ├─ expected_status: 200 | 401 | 403
  ├─ response_body_schema_ref: "@payease/partner-contracts#..."
  └─ error_code_if_403: "FORBIDDEN__ROLE_OUT_OF_SCOPE"
```
