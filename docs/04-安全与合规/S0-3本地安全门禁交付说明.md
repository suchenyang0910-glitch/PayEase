### 2. 金额守卫脚本（CI-10 的 grep 补充防线）

Linux/macOS/WSL：[scripts/check-money-type.sh](file:///e:/PayEase/scripts/check-money-type.sh)
Windows PowerShell 5：[scripts/check-money-type.ps1](file:///e:/PayEase/scripts/check-money-type.ps1)

扫描 18 类金额相关字段名（amount/fee/total/price/principal/interest/balance/repay/discount/refund/rebate/tax/charge/commission/quota/credit/debit/settledAmount…）
**发现 `字段名: number` 立即 exit 1**，并给出例外登记提示。例外需在行尾 `// IGNORE-MONEY-NUMBER` + [SECURITY_EXCEPTIONS.yml.template](file:///e:/PayEase/SECURITY_EXCEPTIONS.yml.template) 双签字登记。

### 3. 许可证 allowlist 扫描脚本（CI-05）

Linux/macOS/WSL：[scripts/check-licenses.sh](file:///e:/PayEase/scripts/check-licenses.sh)
Windows PowerShell 5：[scripts/check-licenses.ps1](file:///e:/PayEase/scripts/check-licenses.ps1)

allowlist 覆盖 22 类 MIT/Apache-2.0/BSD 2-3/ISC/CC0-1.0/0BSD/Unlicense/BlueOak-1.0.0/Artistic-2.0 等；
策略：

- 自己的包 `private=true` 无许可 → 允许（monorepo）
- 其它不在 allowlist 的包 → **exit 1** + 输出 JSON 明细（path/name/version/license）

解决路径：

1. 替换为 allowlist 内替代包；
2. 或 SECURITY_EXCEPTIONS.yml 工程 Owner + 安全 Owner 双签字登记；
3. 或法务审阅后加入 allowlist。
