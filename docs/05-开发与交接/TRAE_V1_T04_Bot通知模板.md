# Trae V1 T04：KhmerXBot 通知模板与深链

**任务类型**：通知事件、三语文案键、深链与幂等。**范围**：KhmerXBot；不发送合同、证件、银行卡号、额度审批规则或完整支付信息。

## 通知规范

- 每条通知由 `notificationId + eventId + templateVersion` 幂等生成。
- 基于用户 `preferredLanguage` 选择 km/en/zh；缺少合规译文时不发布，回退英文并标记内容待审核。
- 链接只使用短时、单次、已签名深链；打开后仍要求有效 Telegram 会话。
- 不在消息正文写完整金额明细、银行卡号、身份证件、合同文本或内部状态名。

## 实现要求

1. 文案以 `templateId + locale` 管理，不将监管/费用文本硬编码进页面。
2. 任何通知失败可重试，但不改变贷款、钱包或还款状态。
3. 需要人工处理的通知必须带工单引用，不给出内部风控原因。
4. 产出 zh/en/km 三语资源文件；最终金融与合同类高棉语文案需法务/本地审核标记后启用。
5. 不发送“工资代扣”“三种回收方式”等旧口径文案；还款通知统一描述为用户主动授权链路。
