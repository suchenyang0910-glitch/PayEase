# 开发任务拆分（V1）

## 0. 交付原则

三个业务域独立仓库/部署单元/数据库：`broker-platform`（助贷）、`lender-core`（持牌机构）、`employer-portal`（企业）。跨域只能调用版本化 API；不得共享数据库。

## 1. 迭代与任务包

| 迭代 | 任务包         | 主要交付物                                          | 依赖         |
| ---- | -------------- | --------------------------------------------------- | ------------ |
| S0   | 基础设施与安全 | 三套环境、CI/CD、密钥、mTLS、审计、监控             | 云/证书决策  |
| S1   | 用户申请与授权 | Telegram 会话、三语、币种、申请、资料上传、授权记录 | 产品文案     |
| S2   | 企业核验       | 企业租户、RBAC、核验待办、批量导入、回调            | S1           |
| S3   | 助贷运营后台   | 资料审核、补件、企业管理、异常工单、费用规则        | S1/S2        |
| S4   | 机构接入与风控 | 机构受理、风控状态、报价快照、合同/放款回调         | 机构接口沙箱 |
| S5   | 结算与贷后     | 独立子账本、对账、账单展示、退款/差异工单           | S4           |
| S6   | 上线质量       | E2E、权限/安全、压测、对账演练、灰度发布            | S1–S5        |

## 2. 助贷平台任务（broker-platform）

| 编号   | 任务                    | 验收标准                                                |
| ------ | ----------------------- | ------------------------------------------------------- |
| BRK-01 | Telegram 登录与会话验证 | 后端验签 `initData`，会话过期/重放被拒绝                |
| BRK-02 | 多语言与币种            | `km/en/zh-CN`、KHR/USD 偏好持久化；金额使用最小货币单位 |
| BRK-03 | 申请状态机              | 仅允许定义状态迁移，产生审计事件                        |
| BRK-04 | 敏感资料服务            | 身份证/银行卡加密、脱敏、短时文件引用、访问审计         |
| BRK-05 | 授权管理                | 字段范围、用途、版本、有效期、撤回和下游通知            |
| BRK-06 | 企业核验编排            | 创建任务、超时、回调验签、异议/重开                     |
| BRK-07 | 运营审核工作台          | 队列、补件、双人复核、SLA、禁止授信决策                 |
| BRK-08 | 助贷费用配置            | 四权审批、规则版本、费用快照、三语披露、退款事件        |
| BRK-09 | 机构连接器              | mTLS、签名、幂等、重试、死信队列、状态归一化            |
| BRK-10 | 通知/客服/审计          | Telegram 通知模板、工单、敏感字段屏蔽、审计检索         |

## 3. 持牌机构任务（lender-core）

| 编号   | 任务              | 验收标准                                |
| ------ | ----------------- | --------------------------------------- |
| LND-01 | 机构申请受理 API  | 签名、权限、幂等、字段/资料引用校验     |
| LND-02 | KYC/AML 编排      | 外部核验、名单筛查、人工复核和原因码    |
| LND-03 | 反欺诈/授信工作流 | 决策版本、人工复核分权、不可覆盖审计    |
| LND-04 | 定价与报价        | 机构利息/费用、还款计划、不可变报价快照 |
| LND-05 | 合同与签约        | 模板版本、签约回调、存证链接            |
| LND-06 | 放款与账单        | 放款指令、账单、还款、冲正、回调事件    |
| LND-07 | 风控后台          | 策略版本、限额、组合预警、审批权限      |

## 4. 企业任务（employer-portal）

| 编号   | 任务             | 验收标准                                |
| ------ | ---------------- | --------------------------------------- |
| EMP-01 | 企业租户与管理员 | 企业隔离、HR/财务/管理员 RBAC           |
| EMP-02 | 核验待办         | 仅展示授权字段；单笔通过/退回/补充      |
| EMP-03 | 批量核验导入     | 模板校验、行级错误、加密存储与过期清理  |
| EMP-04 | 授权与异议中心   | 显示授权范围/有效期，处理员工更正请求   |
| EMP-05 | 企业结算视图     | 仅企业合作服务/分成数据；无个人贷款账务 |

## 5. Definition of Done

- 单元测试、接口契约测试、审计事件、错误码、三语文案、权限测试齐全。
- 金额不用浮点数；费用、报价和账单具备不可变版本和来源事件。
- 所有跨域 API 通过 mTLS、签名、幂等和回调重试测试。
- 业务、合规、机构、企业各自完成 UAT；对账、撤回授权、回调失败和数据访问审计完成演练。
