# 助贷域—持牌机构接口标准 V1

> 本标准定义 KhmerX 助贷域与持牌机构域之间的机器接口，不授权任一方直接访问对方数据库、对象存储、密钥或后台。所有法律主体、费用规则、合同模板和工资代扣安排以上线前法务冻结版本为准。

> **V1 结算边界**：实际放款成功后，KhmerX 按工厂有效费率优先、平台默认费率兜底产生融资居间服务费应收，并在 D+1/D+2/D+3 提醒，D+3 到期。借款利息由用户在还款节点向持牌机构指定账户支付。企业工资执行端仅扣本金。实际放款成功日是计费唯一开始时间；还款严格对齐工厂已冻结的一个或两个发薪节点。KhmerX 不得混入持牌机构利息收入。

## 1. 网络与身份标准

| 项目     | 强制标准                                                                        |
| -------- | ------------------------------------------------------------------------------- |
| 拓扑     | 两台独立服务器/网络域；禁止共享数据库、Redis、对象存储、KMS 和管理员账户        |
| 传输     | TLS 1.2+、双向 TLS（mTLS）、双方固定出口 IP allowlist                           |
| 请求认证 | `X-Partner-Id`、`X-Request-Id`、`Idempotency-Key`、`X-Timestamp`、`X-Signature` |
| 签名     | V1 使用对方登记公钥验签 JWS 或 RSA-PSS-SHA256；不得把共享密钥写进前端或日志     |
| 时钟窗口 | `X-Timestamp` 与服务器时间偏差不超过 5 分钟；超时拒绝并记录安全审计             |
| 幂等     | 同一 `partnerId + eventId` 只能处理一次；重复请求返回原处理结果                 |
| 重试     | 指数退避；超过阈值进入死信队列和人工工单；禁止无限重试                          |

## 2. 统一信封

所有请求和回调使用如下结构：

```json
{
  "eventId": "evt_01J...",
  "eventType": "APPLICATION_PACKAGE_SUBMITTED",
  "schemaVersion": "2026-08-20.v1",
  "occurredAt": "2026-08-20T09:30:00Z",
  "brokerApplicationRef": "KX-APP-...",
  "lenderCaseRef": null,
  "traceId": "trc_...",
  "payload": {}
}
```

约束：

- `eventId` 为 UUID/ULID，不可复用。
- 使用双方各自外部引用；禁止传递数据库 UUID、内部账号 ID 或内部风控模型字段。
- 所有金额使用字符串最小单位，例如 `{ "amountMinor": "50000", "currency": "USD" }`。
- `payload` 中不得出现原始 Bot Token、Cookie、密码、完整银行卡号或签名私钥。

## 3. 助贷域 → 持牌机构域事件

### 3.1 `APPLICATION_PACKAGE_SUBMITTED`

触发条件：助贷资料核验通过、企业 HR 核验通过、用户授权版本完整。

```json
{
  "applicant": {
    "brokerApplicantRef": "KX-U-...",
    "identityDocument": {
      "type": "NATIONAL_ID",
      "artifactRef": "art_...",
      "sha256": "hex"
    },
    "contactArtifactRef": "art_...",
    "payoutAccountArtifactRef": "art_..."
  },
  "application": {
    "requestedAmount": { "amountMinor": "50000", "currency": "USD" },
    "repaymentPreference": {
      "installmentCount": 2,
      "employerPayrollScheduleVersion": "FACTORY-A-PAYDAY-v3"
    },
    "purposeCode": "MEDICAL",
    "submittedAt": "2026-08-20T09:30:00Z"
  },
  "employmentVerification": {
    "employerExternalRef": "FACTORY_A",
    "employmentStatus": "MATCHED",
    "salaryBandCode": "BAND_3",
    "tenureMonths": 18,
    "contractStatus": "ACTIVE",
    "verifiedAt": "2026-08-20T09:00:00Z"
  },
  "consents": [
    { "type": "PERSONAL_DATA", "version": "...", "acceptedAt": "..." },
    { "type": "EMPLOYMENT_VERIFICATION", "version": "...", "acceptedAt": "..." }
  ],
  "artifacts": [
    { "artifactRef": "art_...", "type": "IDENTITY_DOCUMENT", "sha256": "hex" }
  ]
}
```

文件本体不通过公开 URL 传输。持牌机构需通过 mTLS 调用一次性、短时有效的 `artifactRef` 下载接口，或使用双方约定的端到端加密文件包；助贷域不得开放对象存储桶给持牌机构直接浏览。

### 3.2 `BROKERAGE_REMUNERATION_PAYMENT_ACCEPTED`

触发条件：持牌机构已回传实际放款成功；用户已支付融资居间服务费，且已完成助贷财务经办/复核双人确认。

```json
{
  "serviceFee": {
    "ruleVersion": "BROKER-FEE-YYYYMMDD-vN",
    "amount": { "amountMinor": "...", "currency": "USD" },
    "paidAt": "2026-08-20T10:00:00Z",
    "paymentEvidenceRef": "payproof_...",
    "reviewedBy": "BROKER_FINANCE_REVIEWER"
  },
  "finalContractAcknowledgement": {
    "contractVersion": "...",
    "acceptedAt": "...",
    "evidenceRef": "evidence_..."
  }
}
```

该事件仅表示助贷域已确认放款后融资居间服务费支付，**不是**放款指令，也不得要求持牌机构创建、修改或核销借款账。

该事件的负载必须包含费用来源、计费天数与披露版本，供审计和对账使用；不得据此生成或修改持牌机构本息应收账：

```json
{
  "feeDisclosure": {
    "feeRuleVersion": "KX-FEE-YYYYMMDD-vN",
    "feeRateSource": "EMPLOYER_OVERRIDE",
    "repaymentPlanSnapshotRef": "plan_...",
    "actualDays": 22,
    "brokerServiceFee": { "amountMinor": "...", "currency": "USD" },
    "loanPrincipal": { "amountMinor": "...", "currency": "USD" },
    "disbursedAt": "2026-08-20T10:00:00Z"
  }
}
```

`disbursedAt` 必须来自持牌机构实际放款成功回调；助贷域不得自行填充或推算还款节点。

## 4. 持牌机构域 → 助贷域回调

| 事件                        | 用户端归一化状态       | 助贷域允许动作                                         |
| --------------------------- | ---------------------- | ------------------------------------------------------ |
| `APPLICATION_RECEIVED`      | 额度审核中             | 展示受理状态                                           |
| `MORE_INFORMATION_REQUIRED` | 需要补充资料           | 发起补件，不展示内部规则                               |
| `DECISION_AVAILABLE`        | 额度审核结果已更新     | 展示已批准/暂不符合条件/人工复核；保存用户可展示原因码 |
| `FINAL_CONTRACT_READY`      | 请确认合同             | 展示法务批准的合同主体、版本、费用、计划               |
| `DISBURSEMENT_PROCESSING`   | 放款处理中             | 展示状态                                               |
| `DISBURSEMENT_EXCEPTION`    | 放款处理中，请等待处理 | 创建人工工单；不得标记已放款                           |
| `DISBURSED`                 | 款项已发放             | 展示金额、时间、账单摘要                               |
| `REPAYMENT_STATUS_UPDATED`  | 还款计划已更新         | 展示账单摘要与提醒                                     |
| `COMPLAINT_STATUS_UPDATED`  | 投诉处理进度已更新     | 更新工单状态                                           |

`DECISION_AVAILABLE` 最小负载：

```json
{
  "decision": "APPROVED",
  "displayReasonCode": "MANUAL_REVIEW_COMPLETED",
  "approvedAmount": { "amountMinor": "...", "currency": "USD" },
  "repaymentPlan": {
    "employerPayrollScheduleVersion": "FACTORY-A-PAYDAY-v3",
    "installmentCount": 2,
    "items": [
      {
        "sequence": 1,
        "scheduledPayrollDate": "2026-09-10",
        "principalDue": { "amountMinor": "25000", "currency": "USD" },
        "actualDays": 11
      },
      {
        "sequence": 2,
        "scheduledPayrollDate": "2026-09-25",
        "principalDue": { "amountMinor": "25000", "currency": "USD" },
        "actualDays": 26
      }
    ]
  },
  "contractRequired": true,
  "decisionAt": "2026-08-20T10:30:00Z"
}
```

禁止回传持牌机构内部征信记录、模型分数、规则命中详情、内部人员资料或调试日志。

`DISBURSED` 最小负载必须包含 `disbursedAt`、放款本金、已冻结的 `repaymentPlan` 与每期工资扣款本金；计划日期必须由持牌机构按实际放款日和工厂发薪节点版本生成。节假日/非工作日顺延由法务批准规则处理；助贷域只展示该结果，不得自行重算或覆盖。

### 4.1 工资扣款结果回传

企业以后台受控导出清单执行扣款后，由持牌机构或双方确认的人工流程回传标准化结果。V1 仅允许扣贷款本金：

```json
{
  "collectionStatus": "PARTIALLY_COLLECTED",
  "scheduledPayrollDate": "2026-09-20",
  "principalDue": { "amountMinor": "50000", "currency": "USD" },
  "principalCollected": { "amountMinor": "30000", "currency": "USD" },
  "remainingPrincipal": { "amountMinor": "20000", "currency": "USD" },
  "evidenceRef": "collectionproof_...",
  "reportedAt": "2026-09-20T11:20:00Z"
}
```

枚举仅限 `COLLECTED`、`PARTIALLY_COLLECTED`、`NOT_COLLECTED`。部分扣或未扣必须创建人工处理工单；KhmerX 客服可查询和解释状态，但无权核销、调整本金或变更合同。

## 5. 错误码与重试

| HTTP        | 代码                           | 是否重试 | 说明               |
| ----------- | ------------------------------ | -------- | ------------------ |
| 200/201/202 | `ACCEPTED`                     | 否       | 已接收或异步受理   |
| 400         | `SCHEMA_VALIDATION_FAILED`     | 否       | 调用方修正字段     |
| 401         | `PARTNER_AUTH_INVALID`         | 否       | 证书/签名安全事件  |
| 403         | `PARTNER_SCOPE_FORBIDDEN`      | 否       | 合作方越权安全事件 |
| 409         | `EVENT_ALREADY_PROCESSED`      | 否       | 返回既有处理结果   |
| 422         | `BUSINESS_PRECONDITION_FAILED` | 否       | 业务前置条件不满足 |
| 429/503     | `TEMPORARY_UNAVAILABLE`        | 是       | 退避重试           |
| 500         | `INTERNAL_ERROR`               | 是       | 退避重试并告警     |

## 6. 上线验收

1. mTLS 双向认证、签名、时钟窗口、幂等、重试和死信测试全部通过。
2. 断网、重复回调、回调乱序、签名错误、文件哈希不一致均有可追溯处理结果。
3. 助贷侧无法通过 API 修改最终授信、放款、账单或持牌机构决策。
4. 持牌机构侧无法通过接口读取企业 HR 列表、用户 Telegram 会话、助贷运营账号或跨租户资料。
5. Mini App 的普通页面不暴露持牌机构内部信息；最终合同/费用/投诉披露页仍展示法务批准的法定主体。

## 7. 持牌机构信用信息查询预留

### 7.1 域隔离

信用信息查询能力属于持牌机构信贷核心，必须部署在 `lender-core` 内部网络。NBC 负责监管信用报告体系；信用报告服务的实际接入主体、成员资格和技术方式由持牌机构依据其与受监管征信公司的正式协议确认。V1 使用中性名称 `CreditReportingProvider`，不得把未确认的供应商或接口名称硬编码为“NBC API”。

```text
lender-core → CreditReportingProvider → 受监管信用报告服务
       │
       └─ lender_db / lender KMS / lender audit only

broker-api / Mini App / HR portal → 禁止访问
```

### 7.2 查询最小标准

| 控制项     | 强制要求                                                           |
| ---------- | ------------------------------------------------------------------ |
| 调用主体   | 仅持牌机构服务账号；助贷域不得代查                                 |
| 授权       | 查询前验证用户授权版本、用途、语言、签署时间与有效期               |
| 用途限制   | 仅信用资质评估、法定义务或经用户另行授权的用途                     |
| 数据最小化 | 仅提交查询所必需的身份字段；不向助贷域回传原始报告                 |
| 结果使用   | 仅供持牌机构 KYC/风控/人工复核；助贷域只接收标准状态和可展示原因码 |
| 证据       | 记录查询事件、授权引用、供应商交易号哈希、结果哈希、操作者和时间   |
| 默认状态   | `disabled`；缺少成员资格、授权、证书或生产审批时拒绝调用           |

### 7.3 助贷域可接收的唯一结果

```json
{
  "eventType": "DECISION_AVAILABLE",
  "brokerApplicationRef": "KX-APP-...",
  "payload": {
    "decision": "APPROVED",
    "displayReasonCode": "MANUAL_REVIEW_COMPLETED"
  }
}
```

禁止向助贷域发送：信用评分、负面记录、报告 PDF、债务明细、供应商账户号、查询截图、匹配规则或内部风控理由。
