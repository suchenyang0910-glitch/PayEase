# KhmerX 首期组织架构与员工制度（试点版）

> **适用范围：** KhmerX 在柬埔寨的首期受控试点团队。PayEase 是 KhmerX 面向个人用户的金融产品。  
> **文件性质：** 内部管理草案，不替代劳动合同、当地法律、MLVT 要求、税务/社保义务或持牌机构制度；上线前由柬埔寨劳动法律师和人力顾问确认。

## 1. 管理原则

1. 尊重、平等、清晰和可追溯：以高棉语为一线工作语言，英语和中文用于跨团队协作；不得因语言、性别、籍贯、宗教或个人背景歧视员工。
2. 岗位职责与系统权限分离。任何客服、HR、产品或运营人员都不能决定额度、利率、合同、放款或核销。
3. 客户资料只为完成工作而访问；不在私人 Telegram、个人手机相册、Excel 私人副本或聊天群保存。
4. 绩效奖励只奖励服务质量、合规和协作，不以促成借款金额、放款金额、催收金额或拒绝率作为个人 KPI。

## 2. 首期组织架构

```text
执行负责人 / General Manager
├─ 产品与项目组
│  ├─ 产品经理
│  └─ 双语/三语项目助理
├─ 客户运营组
│  ├─ 客服组长
│  └─ 客服专员 ×2
├─ 助贷运营与质量组（试点期间可由负责人兼管）
│  ├─ 资料完整性审核 / 补件协调
│  ├─ 企业核验催办
│  └─ 异常工单、对账协同
├─ 财务与行政（先由负责人或外包专业服务覆盖）
└─ 合规、数据保护与技术安全（负责人 + 外部顾问）
```

### 2.1 岗位与权限边界

| 岗位       | 首期编制/预算                                       | 主要职责                                 | 明确禁止                                  |
| ---------- | --------------------------------------------------- | ---------------------------------------- | ----------------------------------------- |
| 执行负责人 | 1 人，USD 6,000/月（预算）                          | 经营、预算、合作方、重大升级审批         | 绕开双人复核处理资金、以个人账户收款      |
| 产品经理   | 1 人，USD 2,000–2,500/月；另按合同承担签证/住宿支持 | 产品、需求、验收、培训材料、数据复盘     | 查看超出工作必需的原始 KYC、决定授信/放款 |
| 项目助理   | 1 人，USD 800–1,200/月                              | 三语协调、会议纪要、项目跟进、培训排期   | 代替有权人审批客户/资金事项               |
| 客服组长   | 1 人，USD 600/月                                    | 排班、质检、升级、培训、SLA 与工单闭环   | 修改费用、额度、合同、放款或还款核销      |
| 客服专员   | 2 人，USD 300–400/人/月                             | 三语咨询、身份核验后的工单受理、流程提醒 | 索取密码/OTP/完整卡号；承诺审批结果       |

以上为首期预算，不是劳动合同承诺；试用期、税前/税后口径、签证、住宿、法定福利、加班、假期和终止条件必须在当地合规劳动合同中明确。

## 3. 招聘与入职

### 3.1 项目助理

- 可用中文、高棉语和英语完成日常口头及书面沟通。
- 熟练使用电脑与常用办公软件，能维护任务清单、会议纪要、培训记录和受控表格。
- 具备基础协调和现场管理能力：能推动负责人、记录阻塞、按时升级，而不是替他人作决定。
- 入职前完成：身份与推荐人核验、保密/数据保护承诺、信息安全培训和反欺诈培训。

### 3.2 客服组长与客服专员

岗位条件、培训和禁止性行为详见同目录的《KHMERX_客服SOP与初始话术》。客服组长需要高棉语母语或等效工作能力，并能用中文、英语与管理层沟通；客服专员至少能以高棉语稳定服务，具备基础中文或英语沟通能力。

## 4. 工作、考勤与沟通制度

1. 首期客服服务时段：08:00–18:00（柬埔寨时间）；排班、休息、加班、节假日和法定休假以经当地顾问确认的劳动合同与排班表为准。
2. 工作时间内使用公司批准的账号、设备、工单和文件空间；远程访问仅允许从受管设备和经批准网络进行。
3. 迟到、缺勤、调班、病假和紧急情况须向直属负责人报告；记录应最小化，不要求员工在群聊公开健康或家庭隐私。
4. 中文、英语和高棉语文案出现歧义时，以经审核的高棉语用户模板为准，并由客服组长升级确认。
5. 任何利益冲突、亲属申请、企业 HR/合作方私下索取资料、疑似贿赂或胁迫，均须立即停止处理并升级执行负责人和合规联系人。

## 5. 薪资、奖励与绩效

### 5.1 薪资原则

- 固定薪资按当地劳动合同约定周期支付；薪资、补贴、税费和法定缴纳项目应提供可核对记录。
- 不用客户借款额、放款额、服务费收取额、拒绝率、投诉压低率作为客服或 HR 的个人提成指标。
- 任何奖金都不能改变员工拒绝违规指令、报告问题或暂停高风险工单的权利。

### 5.2 月度绩效奖励建议

| 维度           | 参考权重 | 合格证据                               |
| -------------- | -------: | -------------------------------------- |
| 服务质量与时效 |      35% | 抽检准确、SLA 达标、无虚假承诺         |
| 合规与数据安全 |      35% | 无严重违规；正确升级敏感事项；完成培训 |
| 协作与记录质量 |      20% | 工单字段完整、交接清楚、跨语言误解少   |
| 改进贡献       |      10% | 被采纳的 FAQ、流程改进或风险提示       |

- 建议月度浮动奖励上限为该岗位月固定薪资的 10%–20%，由负责人和非直接主管双人复核。
- 重大违规、伪造记录、泄露数据、绕过审批、索取或记录密码/OTP/完整银行卡号，当月不参与奖励，并按劳动合同、调查程序和当地法律处理。
- 奖励结论必须有可审计证据，员工可在合理时限内提出复核；不得以口头印象替代记录。

## 6. 培训、试用与晋升

1. 入职首周完成：产品边界、客服 SOP、三语话术、隐私与反诈骗、投诉升级、信息安全、反歧视与反骚扰培训。
2. 试用期以当地劳动合同为准。试用评估至少基于培训通过、模拟工单、服务质量和合规表现，不以借款转化作为唯一标准。
3. 晋升或调岗前复核语言能力、记录质量、合规记录和岗位最小权限；先撤旧权限，再授新权限。

## 7. 纪律、申诉与退出

1. 处分应当事实清楚、比例适当、记录可追溯，并给予员工陈述与申诉渠道；涉及劳动法的调查和处分先由当地顾问复核。
2. 员工可向执行负责人或指定的独立联系人报告骚扰、歧视、安全事件、舞弊或不当指令；禁止报复。
3. 离职、调岗或长期休假时，先撤销系统和群组权限、收回设备、完成工单交接，再办理其余行政流程。
