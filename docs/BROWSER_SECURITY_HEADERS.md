# PayEase 浏览器安全响应头配置矩阵（S0.1 模板，联调后 TODO 处再填实）

> 对应基线 §1.9 WEB-01 ~ WEB-08。
> **关键实现原则**：
>
> 1. 管理后台 (admin._) 与 Telegram Mini App (miniapp._) **必须** 使用独立配置；
> 2. `frame-ancestors` 白名单待 Telegram Web 容器 + 手机端联调后再写入固定策略，**禁止** 假设带路径的 URL 为长期稳定；
> 3. 生产部署优先在 ALB / CloudFront Response Headers Policy 注入，应用层只作为回退冗余。

---

## A. 管理后台（独立响应头配置）

域名示例：`admin.payease-example.kh`
部署层：CloudFront 行为 `admin/*` + ALB 响应头策略 `policy-admin-v1`

| Header                       | 值                                                                                                                                                                                                                                                            | 说明                                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Strict-Transport-Security    | `max-age=63072000; includeSubDomains; preload`                                                                                                                                                                                                                | WEB-01 强制 HTTPS，包含子域 + 预加载                                                                       |
| Content-Security-Policy      | `default-src 'self'; script-src 'self' 'nonce-{NONCE}'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'; worker-src 'none'; manifest-src 'self';` | WEB-02：严格 CSP。**frame-ancestors = none** 禁止任何嵌入，管理后台无 iframe 使用场景                      |
| X-Frame-Options              | `DENY`                                                                                                                                                                                                                                                        | 兼容未实现 CSP 的旧浏览器                                                                                  |
| X-Content-Type-Options       | `nosniff`                                                                                                                                                                                                                                                     | WEB-04 防止 MIME 嗅探                                                                                      |
| Referrer-Policy              | `strict-origin-when-cross-origin`                                                                                                                                                                                                                             | WEB-06 跨域仅发送 Origin                                                                                   |
| Permissions-Policy           | `geolocation=(), microphone=(), camera=(), payment=(), clipboard-write=(), clipboard-read=(self), idle-detection=(), screen-wake-lock=(), serial=(), usb=(), storage-access=()`                                                                               | WEB-07 默认禁止全部高风险 API                                                                              |
| Cross-Origin-Opener-Policy   | `same-origin`                                                                                                                                                                                                                                                 | 防止跨源弹窗共享上下文                                                                                     |
| Cross-Origin-Resource-Policy | `same-origin`                                                                                                                                                                                                                                                 | 非同源禁止加载本域资源                                                                                     |
| Cross-Origin-Embedder-Policy | `require-corp`                                                                                                                                                                                                                                                | 配合 CORP/COOP                                                                                             |
| Set-Cookie (模板)            | `session=...; Path=/; HttpOnly; Secure; SameSite=Strict; Max-Age=1800; Partitioned;`                                                                                                                                                                          | WEB-03：**双保险** `HttpOnly + Secure + SameSite=Strict`，30 分钟会话。Session 不在 localStorage（WEB-08） |

## B. Telegram Mini App（独立响应头配置，**必须与管理后台分离**）

域名示例：`app.payease-example.kh`
部署层：CloudFront 行为 `app/*` + ALB 响应头策略 `policy-miniapp-v1`

| Header                       | 值                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | 说明                                                                                                                                                                                                                          |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Strict-Transport-Security    | `max-age=63072000; includeSubDomains; preload`                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | 与后台一致                                                                                                                                                                                                                    |
| Content-Security-Policy      | `default-src 'self'; script-src 'self' 'nonce-{NONCE}' https://telegram.org/js/telegram-web-app.js; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; img-src 'self' data: https://t.me https://cdn.telegram.org; font-src 'self' https://fonts.gstatic.com data:; connect-src 'self' https://t.me https://api.telegram.org; object-src 'none'; base-uri 'self'; form-action 'self'; **frame-ancestors TODO_FILL_AFTER_INTEGRATION**; worker-src 'self'; manifest-src 'self'; upgrade-insecure-requests;` | WEB-02：放宽 Telegram 脚本/静态。`frame-ancestors` 留 TODO，联调结束后仅填写允许的源（origin，**不含路径**），例如最终可能为 `https://web.telegram.org https://t.me`。不要加入 `https://web.telegram.org/a/` 或任何带路径 URL |
| X-Frame-Options              | **不设置**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Mini App 在 Telegram iframe 内，本头 DENY 会直接阻断渲染；完全交给 CSP frame-ancestors                                                                                                                                        |
| X-Content-Type-Options       | `nosniff`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | WEB-04                                                                                                                                                                                                                        |
| Referrer-Policy              | `strict-origin-when-cross-origin`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | WEB-06                                                                                                                                                                                                                        |
| Permissions-Policy           | `geolocation=(), microphone=(self), camera=(self), clipboard-write=(self), clipboard-read=(self), payment=(), usb=(), serial=(), screen-wake-lock=()`                                                                                                                                                                                                                                                                                                                                                                  | Mini App 可能需要扫码/拍照，谨慎开启 camera/microphone 为 self                                                                                                                                                                |
| Cross-Origin-Opener-Policy   | `same-origin-allow-popups`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | 允许 Telegram 相关弹出                                                                                                                                                                                                        |
| Cross-Origin-Resource-Policy | `cross-origin`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Telegram 容器需从跨源加载；配合 CORS 白名单精确化                                                                                                                                                                             |
| Cross-Origin-Embedder-Policy | `unsafe-none`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Mini App 嵌入外部资源宽松模式                                                                                                                                                                                                 |
| Set-Cookie (模板)            | `session=...; Path=/; HttpOnly; Secure; SameSite=None; Max-Age=7200; Partitioned;`                                                                                                                                                                                                                                                                                                                                                                                                                                     | WEB-03：**Mini App 在第三方 iframe 场景必须 SameSite=None + Secure**，否则 Safari/Chrome 会拒收。Web 存储仍禁止 localStorage 存 token（WEB-08）                                                                               |
| CSRF 头配合                  | `X-CSRF-Token` 双提交 Cookie + Header（WEB-03）                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | BFF 层校验                                                                                                                                                                                                                    |

## C. 跨域 CORS 精确白名单（WEB-03 不得使用 `*`）

- 管理后台 API：白名单仅包含 `https://admin.payease-example.kh` + preview 域名（`https://deploy-preview-X.payease-example.kh`）
- Mini App BFF API：白名单仅包含 `https://app.payease-example.kh` + 测试环境 `https://app-staging.payease-example.kh`
- 跨域 mTLS 的 broker↔lender↔employer：不走 CORS，按 §1.1 ISO-06 专用 VPC/IPsec + mTLS

## D. 落地验收检查点（S1-7.5 / S0→S1 门禁 7.3）

1. [ ] curl admin 域名：CSP `frame-ancestors 'none'` 有；XFO=DENY 有
2. [ ] curl miniapp 域名：CSP `frame-ancestors TODO` 已替换为精确源 (无路径)；**X-Frame-Options 响应中完全不出现**
3. [ ] Set-Cookie admin=Strict / miniapp=None+Secure+Partitioned
4. [ ] 前端构建产物 `<script>` / `<link>` 均含 `integrity=` (SRI，WEB-07 回退)
5. [ ] localStorage 扫描测试中未出现 token/签名会话（WEB-08 通过）
6. [ ] CORS preflight 非白名单 Origin 响应 403，`Access-Control-Allow-Origin` 精确匹配而非 `*`
