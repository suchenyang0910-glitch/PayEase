## 文档维护规则

1. 新文档先归类，禁止重新堆放在仓库根目录或 `docs/` 根目录。
2. 需要 Trae 编码的内容以 `TRAE_` 前缀放入 `02-品牌与官网` 或 `05-开发与交接`。
3. 可公开品牌与官网材料只能放入 `02-品牌与官网`；KYC、合同、真实账号、Token、真实用户资料禁止进入任何文档。
4. 所有跨文档引用使用仓库相对路径；移动文件后必须运行链接检索并同步更新。
5. 法律、费用、隐私、投诉、催收与电子签约内容须标记版本、适用主体、生效日期与审校状态。
