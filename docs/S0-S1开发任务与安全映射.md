# S0 / S1 开发任务拆分与安全映射（v2，含 8 处表述修正 + 9 类新增项）

> 分级规则：
>
> - **P0**：阻塞后续迭代；安全红线；未通过不得进入下一阶段
> - **P1**：V1 必须，但可与本迭代其他任务并行；上线前必完
> - **P3**：V1.1 增强，可延后；不阻塞上线

**准入条件**：

- S0 所有 P0 通过 → 允许进入 S1
- S1 所有 P0 通过 → 允许进入 S2
- [安全基线 §4 上线红线 12 项](file:///e:/PayEase/docs/安全基线与上线验收清单.md#L184-L199) 全通过 → 允许接入真实用户

**关键表述修正说明（v2 vs v1）**：

- ISO-01：默认禁止跨域信任；仅允许受控只读审计角色
- AUTH-03：登录交换接口同 initData 短窗口（60s）幂等返回同一会话，不得一律拒绝
- ENC-03：V1 = **服务端**信封加密 + S3 SSE-KMS 双保险（非客户端加密）
- ENC-07：预签名 URL 有效期 ≤ 5min + 承认有效期内可复用；若需一次性需额外令牌服务
- FILE-07：替换脚本标签检测 → 图片重新编码清元数据 + PDF 恶意内容/宏/压缩包禁止
- AUD-01：**审计表禁止 UPDATE/DELETE**（非软删）；业务实体可软删但必须新增审计事件
- RES-03：SQS/SNS 无需显式多 AZ（区域级托管）；重点在 ECS/RDS/Redis；**RES-06 补：随机抖动 + 最大重试 6 次 + 总窗口 24h + 熔断**
- BIZ-03：撤回按阶段处理，签约后/放款中撤回转为取消工单，不承诺「阻止放款」
