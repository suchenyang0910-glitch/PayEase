# S0.5 静态演示代码审查与验收清单

## 目的与边界

本清单只适用于受控、密码保护、合成数据的 HR/财务静态演示。它不是生产放行，不允许把演示环境升级为真实试点。

在 S0.2 签字完成前，以下事项一律禁止：真实 AWS/IdP、HRIS、银行、支付、持牌机构接口；真实 PII、合同或资金数据；任何自动授信、放款或还款核销。

## A. 提交范围审查（阻断项）

- [ ] 仅包含演示入口、演示构建配置、审查/部署文档和必要测试；没有无关重构。
- [ ] `dist-demo/`、`dist/`、压缩包、日志、截图、`.env*`、密钥与任何真实数据均未被 Git 暂存。
- [ ] 演示入口与正常应用入口在构建模式上明确隔离；默认生产构建不被演示代码替换。
- [ ] 没有删除或弱化租户隔离、证件加密/HMAC、金额字符串、审计不可篡改、多 Bot 等既有安全约束。

## B. 网络与数据零接触（阻断项）

- [ ] 演示入口、页面与 mock 目录不存在 `fetch`、`axios`、`XMLHttpRequest`、`WebSocket`、`sendBeacon` 或第三方分析 SDK。
- [ ] 不含银行、支付、HRIS/ERP、持牌机构域名或 SDK 标识。
- [ ] 全部展示记录为明显合成数据；不得复刻真实姓名、身份证/护照号、手机号、工资、银行账户、合同或投诉记录。
- [ ] 金额使用 `{ amountMinor: string, currency }`；不得用 JavaScript `number` 表达金额 DTO。
- [ ] 浏览器中不使用 `localStorage` / `sessionStorage` 保存 token、凭证、密钥、`initData` 或个人资料。

## C. 演示功能与权限语义

- [ ] HR 仅展示本工厂的模拟就业核验，并且只显示 `MATCHED` / `NOT_MATCHED` 结果；不展示证件原文、手机号、工资或跨工厂数据。
- [ ] 财务门户只展示合成还款计划和对账差异；没有真实支付、核销或账务写入能力。
- [ ] 所有登录、审批、核验、对账按钮均显式标注为“演示/不提交”，且不会发起网络请求。
- [ ] 页面提供中文、英文、高棉语文本或明确的语言缺口记录；不得将单语演示误称为 V1 可用产品。
- [ ] 页面安全头设计与后台一致：`X-Frame-Options: DENY`、CSP `frame-ancestors 'none'`、`connect-src 'self'`。

## D. 本地验收记录

以下命令全部退出码为 0，并将命令、操作者、时间与对应提交 SHA 记录在变更单中：

```powershell
pnpm --filter @payease/hr-verify-portal run typecheck
pnpm --filter @payease/finance-verify-portal run typecheck
scripts\build-demo-portals.cmd
scripts\check-money-type.ps1
scripts\check-licenses.ps1
```

- [ ] 构建脚本的 Network-Zero 与金额字符串检查均通过。
- [ ] GitHub Actions 的质量与安全工作流在待发布提交上均为绿色。
- [ ] 人工打开两个 zip，确认仅有静态 Web 资源，且无 `.env`、源码仓库元数据、日志或密钥文件。

## E. 受控部署前置条件

- [ ] 本清单由工程负责人和安全负责人复核；任何例外都有原因、范围、到期日和双签字。
- [ ] HR 与财务分别使用独立 Basic Auth 文件和账号；密码通过安全渠道传递，不写入仓库、工单或截图。
- [ ] 使用独立演示子域名与单域名证书，不复用生产主机、SSH 主机密钥、认证文件或证书。
- [ ] 部署后按 `S0_5_DEMO_DEPLOYMENT.md` 的 7 项烟雾测试留存结果；任一失败立即下线相关 vhost。
