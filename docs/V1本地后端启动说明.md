# V1 本地后端启动说明

本说明只用于本机开发与受控测试；禁止复制到 VPS 预览环境或生产环境。

## 已落地范围

- `broker-platform/db/migrations/V0001__controlled_pilot.sql`：用户语言偏好与 Telegram 引用、申请、审批、资金凭证及审计事件表。
- 所有资金字段均为 `BIGINT` 最小货币单位，首期只允许 USD 10–500 与 7–180 天。
- 审批、状态、资金凭证和审计事件均为追加写；数据库触发器禁止更新或删除。
- `infra/local/docker-compose.yml`：仅绑定 `127.0.0.1:54329` 的 PostgreSQL 16 本机实例。

## 启动

```powershell
$env:PAYEASE_LOCAL_POSTGRES_PASSWORD = "choose-a-local-only-password"
docker compose -f infra/local/docker-compose.yml up -d
docker compose -f infra/local/docker-compose.yml ps
```

首次启动会自动执行迁移。删除本地卷会销毁测试数据，不得在任何含真实数据的环境执行。

`PAYEASE_LOCAL_POSTGRES_PASSWORD` 只可保存在本机临时终端环境变量中；不得提交到 Git、复制到 VPS，或用于任何真实环境。

## 后续 API 接入约束

- Telegram `initData` 只能由服务端验签；前端不能创建会话。
- 人工放款与核销必须先写两个不同账号的审批事件，再写资金凭证。
- 真实机构、企业、银行与支付通道 API 在 S0.2 签字和合作协议完成前不得启用。
