# 三语用户协议与披露清单

本文件是文案与法务交付清单，不替代当地执业律师、持牌机构或监管要求确认的最终文本。

## 1. 必备文件

| 文件                     | 中文 | English | ខ្មែរ | 责任方                     |
| ------------------------ | ---- | ------- | ----- | -------------------------- |
| 隐私政策                 | 必备 | 必备    | 必备  | 助贷公司 + 法务            |
| 个人信息与企业核验授权书 | 必备 | 必备    | 必备  | 助贷公司 + 企业 + 法务     |
| 助贷服务协议             | 必备 | 必备    | 必备  | 助贷公司 + 法务            |
| 持牌机构贷款合同及费用表 | 必备 | 必备    | 必备  | 持牌机构                   |
| 报价确认页               | 必备 | 必备    | 必备  | 持牌机构提供数据，助贷展示 |
| 还款、投诉和争议处理说明 | 必备 | 必备    | 必备  | 持牌机构 + 助贷公司        |
| 授权撤回与数据请求说明   | 必备 | 必备    | 必备  | 助贷公司                   |

## 2. 用户旅程披露点

| 节点                | 必须展示并确认的内容                                                   |
| ------------------- | ---------------------------------------------------------------------- |
| Telegram 授权后     | 隐私政策、语言选择、客服/投诉入口                                      |
| 上传身份证/银行卡前 | 资料用途、接收方、保存规则、加密与访问说明                             |
| 企业核验前          | 核验字段、企业名称、用途、有效期、撤回方式                             |
| 提交申请前          | 助贷服务性质、非持牌放款主体说明、服务收费（如适用）                   |
| 收到报价后          | 本金、利息、所有费用、收费主体、到账金额、总还款、还款计划、报价有效期 |
| 合同签署前          | 持牌机构名称、合同、费用表、还款与投诉机制                             |
| 放款/账单后         | 放款状态、账单、还款入口、争议和困难还款支持入口                       |

## 3. 多语言质量要求

- 以持牌机构和法务批准的同一语义源文本为准，分别生成 `zh-CN`、`en`、`km` 版本并记录版本号。
- 高棉语、英语和中文的关键金额、日期、收费主体、权利义务不得出现语义差异；金额与日期由结构化数据渲染，避免人工翻译错误。
- 法律/合同文本不使用机器翻译直接上线；须由具备当地法律语境能力的审核人签核。
- 用户每次确认记录语言、文本版本、时间、申请 ID、设备/会话参考和文本哈希。

## 4. 文案交付格式

每份文件交付：标题、语言、版本、发布日期、生效日期、全文 HTML/Markdown、文本哈希、审核人、失效版本、适用产品/机构。前端使用 CMS/文案包按版本拉取，已确认申请永久关联当时的文本快照。
