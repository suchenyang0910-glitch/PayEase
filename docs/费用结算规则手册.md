# 费用结算规则手册

## 1. 基本原则

机构利息及机构费用由持牌机构定价、出具合同与账单；助贷服务费/手续费由助贷公司独立计费和结算；企业分成属于企业合作结算。三类账务分别入账、分别对账、分别出具凭证。V1 支持柬埔寨瑞尔（KHR）与美元（USD），单笔申请/报价/合同/账单只允许一种币种，禁止在账单内混币种计算。所有向用户收取的费用须在签约前逐项披露并完成适用审核。

## 2. 费用规则生命周期

`草稿 → 业务复核 → 合规/法务复核 → 财务/税务复核 → 机构确认（如适用） → 已发布 → 已停用/失效`

已发布规则不可编辑，只能复制为新版本。申请进入报价后写入 `fee_snapshot`；后续规则变更不影响已冻结快照。

## 2.1 放款扣费与还款方式

| 配置项   | 可选值                                                               | 用户披露要求                                           |
| -------- | -------------------------------------------------------------------- | ------------------------------------------------------ |
| 放款扣费 | `NONE`（不扣）/ `DEDUCT_FROM_DISBURSEMENT`（放款时扣除经批准费用）   | 必须展示借款本金、扣除项目、实际到账金额；禁止隐性扣减 |
| 计息基础 | `DECLINING_BALANCE`（按剩余本金）/ `FLAT_ADD_ON`（按初始本金预计算） | 显示计算方法、名义利率、适用总成本口径及完整还款计划   |
| 分期方式 | `EQUAL_INSTALLMENT`（每期固定总还款）/ 其他经批准方式                | 展示每期本金、利息、费用、总应还及到期日               |

“砍头息”通常指放款时从本金中预先扣除利息或与贷款实质相关的收费、但合同本金仍按全额计算的安排。产品默认应设为 `NONE`；如任何合法且经批准的放款扣费被启用，系统必须把扣除金额、实际到账金额、费用主体和退款规则纳入报价、合同及账单，且不得以隐藏项目实现。

### 还款方式术语

1. **等额本息 / 按剩余本金摊还（amortizing equal installment）**：每月还款总额固定，利息按剩余本金计算；本金占比逐月提高。
2. **固定利息平摊 / 加成利息（flat-rate or add-on interest）**：利息先按初始本金预计算，再与本金平均分摊到各期。虽然每期金额固定，但其实际资金成本通常高于表面名义利率，必须额外显示适用的总成本口径。

示例：借款 USD 10,000、12 期、总还 USD 11,800，每期 USD 983.33。这是**固定利息平摊（flat/add-on）**的例子：USD 1,800 是按初始本金预计算后均摊，不是“18% 年化、按剩余本金计算”的等额本息。系统必须同时展示完整还款计划和机构/法务确认的年化总成本披露口径，不能只显示“18%”。

## 3. 收费规则字段

| 字段                     | 说明                                              |
| ------------------------ | ------------------------------------------------- |
| 费用编码、名称、收费主体 | 唯一标识及法定收款主体                            |
| 计算方法                 | 固定额、比例、阶梯；金额以最小货币单位计算        |
| 放款与分期规则           | 是否放款扣费、计息基础、分期方式、还款日规则      |
| 适用范围                 | 产品、机构、企业、渠道、币种、金额/期限区间、日期 |
| 收取时点                 | 签约、放款后、服务履约节点或其他经批准时点        |
| 披露文本                 | 高棉语、英语、中文及版本号                        |
| 退款规则                 | 可退/不可退条件、触发事件、审批角色、时限         |
| 税务与开票               | 税码、会计科目、凭证/发票模板                     |

## 4. 结算流程

1. 机构发送已签约/已放款/账单事件；助贷仅接收并验证事件。
2. 助贷收费引擎根据冻结规则和服务履约事件生成 `broker_fee_receivable`，不得直接改写机构信贷账。
3. 企业分成引擎根据独立合作合同和履约依据生成 `enterprise_share_payable`，不得与单个员工的授信、利率或催收挂钩。
4. 每日按事件 ID、申请号、合同号、币种、金额、税额生成三方对账单。
5. 差异进入工单；未经审批不得手工调账。退款/冲正产生反向凭证并关联原始事件。

## 5. 对账口径

| 对账对象     | 对账内容                             | 权威来源          |
| ------------ | ------------------------------------ | ----------------- |
| 机构 vs 助贷 | 审批、签约、放款、机构费用、账单状态 | 机构账务/回调事件 |
| 助贷内部     | 服务履约、服务费、手续费、退款、税费 | 助贷独立子账本    |
| 助贷 vs 企业 | 企业服务履约、分成、发票、付款状态   | 双方确认的结算单  |

## 6. 用户可见披露

在报价确认和签约前，以用户选择语言显示：借款本金、利息、每项费用、收费主体、实际到账金额、总还款额、每期金额与日期、退款条件、投诉入口。任何费用变更均需新快照和重新确认。
